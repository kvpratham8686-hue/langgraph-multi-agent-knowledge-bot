# LangGraph Multi-Agent Knowledge Bot 🤖🧠

A production-ready **multi-agent AI system** built using **LangGraph**, **FastAPI**, and modern LLM tooling.  
This project demonstrates agent orchestration, graph-based workflows, and API-driven AI systems.

---

## ✨ Features

- Multi-agent collaboration using LangGraph
- Modular agent architecture
- FastAPI backend for easy integration
- Clean, scalable, interview-ready project structure
- Easy setup and extensible design

- LangChain
