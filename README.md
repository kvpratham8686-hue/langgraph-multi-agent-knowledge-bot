\# LangGraph Multi-Agent Knowledge Bot



\## 📌 Project Overview

This project is a \*\*LangGraph-based Multi-Agent Knowledge Bot\*\* built using \*\*Python\*\* and \*\*FastAPI\*\*.  

It demonstrates how multiple AI agents can collaborate using a graph-based workflow to process user queries and return structured responses.



The system exposes a REST API and provides interactive API documentation using \*\*Swagger UI\*\*.



---



\## 🧠 Key Features

\- Multi-agent orchestration using \*\*LangGraph\*\*

\- FastAPI backend for API access

\- Modular project structure

\- Swagger UI for easy testing

\- Clean, production-ready codebase
